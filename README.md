# RPSBR
A little SDL3 game where many icons of Rock Paper Scissors battle to win. **It gets quite chaotic!**

## Command-line options

`-c` - Set the number of icons.  
`-w` - Set the width of the window.  
`-h` - Set the height of the window.  
`-i` - Enable Infection mode  

## Infection mode
*Infection mode* is a mode in which icons don't kill each other, but instead convert each other. Example: when scissors touches paper, that paper turns into scissors too.
